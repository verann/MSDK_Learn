# MSDK_Learning
ТЗ для приложения:
создать приложение для записи в барбер-шоп
1. Приветственный экран (Onboarding / Splash)
Визуальный ряд: Анимированный логотип (вращающиеся ножницы из прямых линий). На фоне — зацикленное видео без звука: макро-съемка падающих волос на кожаный фартук или движение опасной бритвы по ремню.
Текст: Крупно «Твоя стрижка. Твой график.» Подзаголовок более тонким шрифтом: «Запись в один свайп».
Кнопка: В самом низу экрана плавающая кнопка-призрак (без заливки, только контур): «Продолжить». При нажатии она плавно трансформируется в индикатор загрузки следующего экрана.
Особенность: Отсутствие регистрации на этом этапе. Переход к выбору мастера происходит мгновенно после касания.
2. Экран выбора мастера
Компоновка: Горизонтальный скролл карточек профилей (карусель). Каждый мастер занимает почти весь экран по ширине, карточки слегка перекрывают друг друга.
Карточка мастера: 
Слева крупное фото-портрет (4:5), обрезанное так, чтобы была видна татуировка на шее или деталь интерьера барбершопа.
Справа поверх фото наложен вертикальный полупрозрачный блок цвета графита.
Внутри блока: Имя (крупно), Специализация (например, «Королевское бритьё», «Фейды любой сложности»), рейтинг (звездочки) и маленькая иконка-сердечко для добавления в избранное.
Интерактивность: При долгом нажатии на карточку фотография меняется на короткое беззвучное видео процесса работы мастера. Свайп вниз закрывает карусель и показывает карту со всеми филиалами.
Нижняя панель: Закреплена прозрачная плашка с текстом «Выбрать [Имя]» и стрелкой вправо. Кнопка неактивна до момента выбора.
3. Экран выбора услуги
Логика: Открывается сразу после выбора мастера. Дизайн поддерживает контекст: вверху остается закрепленная мини-карточка выбранного барбера.
Группировка: Услуги разделены на смысловые блоки с крупными буквицами в стиле старых цирюльников: «Стрижки», «Бритьё», «Уход», «Оформление бороды».
Элементы списка: Минималистичные чекбоксы. Вместо стандартных галочек используется закрашивание названия услуги фирменным медным цветом. 
Детали: Каждая услуга имеет мелкий серый подстрочник (например, «включает мытье головы и укладку») и цену справа. 
Множественный выбор: Пользователь может выбрать несколько услуг (например, стрижка + камуфляж седины). При выборе нескольких пунктов внизу автоматически собирается корзина с итоговой суммой.
Переход: После отметки хотя бы одной услуги нижняя кнопка меняет цвет с серого на медный и надпись на «Далее: Дата и время».
4. Экран выбора даты и времени
Верхняя часть: Календарь. Отображается текущий месяц. Выходные дни подсвечены легким оттенком меди, прошедшие даты заблокированы. Выбранная дата выделяется плотной заливкой.
Основная часть: Интерактивная временная сетка (тайм-слоты). Сетка разбита на блоки по 15 минут. Занятые слоты перечеркнуты тонкой белой линией и имеют нулевую прозрачность. Свободные слоты активны.
Динамика: При тапе на свободное время слот мягко увеличивается в масштабе (ховер-эффект), внутри появляется пульсирующая точка медного цвета, а сам слот приобретает теплый янтарный оттенок.
Нижняя панель: Как только выбрано время, выдвигается жесткая шторка снизу (Bottom Sheet) с деталями заказа: имя мастера, услуга, адрес, итоговое время. Здесь же находится большая кнопка «Забронировать за Х ₽».
Умный ассистент: Над календарем есть микро-текст «Подобрать ближайшее окно?». При нажатии алгоритм подсвечивает ближайшие свободные слоты у этого мастера во всех филиалах.
5. Экран подтверждения
Обратная связь: Полноэкранная анимация успеха. Иконка ножниц схлопывается, превращаясь в аккуратную галочку. Появляется легкая тактильная вибрация (Haptic Feedback).
Главный текст: «Готово. Мы вас ждем.»
Детализация: Карточка бронирования, дублирующая всю информацию: QR-код для администратора (сканируется на входе), дата, время, имя мастера, точный адрес с кнопкой построения маршрута, телефон салона.
Управление бронью: Сразу под карточкой две крупные кнопки:
«Добавить в календарь» (с иконками Apple/Google Calendar).
«Напомнить за 2 часа» (активировано по умолчанию, переключатель).
Дополнительные действия: Блок «Что еще?» предлагает добавить услугу экспресс-ухода за кожей (+15 минут к записи) или купить сертификат в подарок.
Нижняя навигация: Кнопка «Готово», которая возвращает пользователя на самый первый экран приветствия, но уже с маленькой зеленой точкой над вкладкой «История записей» в нижней панели навигации всего приложения.
